## 1. バリデーション方針

バリデーションはフロントエンドとサーバーサイドの**2段階**で実施する。

| 実施場所 | タイミング | 目的 |
|---------|----------|------|
| フロントエンド | 送信ボタン押下時 / 画像選択時 | ユーザーへの即時フィードバック |
| サーバーサイド（API Routes） | リクエスト受信時 | フロントエンドバイパス対策・セキュリティ |

## 2. レシピフォームのバリデーション

対象画面: S-02（レシピ登録）・S-04（レシピ編集）

### 2.1 入力項目一覧

| No. | 項目名 | 必須 | 文字数・範囲 | 形式 |
|-----|--------|------|------------|------|
| 1 | レシピ名 | ○ | 1〜255文字 | テキスト |
| 2 | カテゴリ | × | — | セレクトボックスの値 |
| 3 | 説明文 | × | 上限なし | テキスト |
| 4 | 調理時間 | × | 1〜9999（分） | 正の整数 |
| 5 | 何人前 | × | 1〜99（人） | 正の整数 |
| 6 | 材料 | ○ | 1文字以上 | テキスト（改行区切り） |
| 7 | 作り方 | ○ | 1文字以上 | テキスト（改行区切り） |

### 2.2 エラーメッセージ一覧

| 項目名 | 条件 | エラーメッセージ |
|--------|------|----------------|
| レシピ名 | 未入力 | 「レシピ名を入力してください」 |
| レシピ名 | 255文字超 | 「255文字以内で入力してください」 |
| 調理時間 | 数値以外 | 「数値を入力してください」 |
| 調理時間 | 1未満または9999超 | 「1〜9999の範囲で入力してください」 |
| 何人前 | 数値以外 | 「数値を入力してください」 |
| 何人前 | 1未満または99超 | 「1〜99の範囲で入力してください」 |
| 材料 | 未入力 | 「材料を入力してください」 |
| 作り方 | 未入力 | 「作り方を入力してください」 |

### 2.3 エラー表示方法

```
  レシピ名 *
  ┌─────────────────────────────────────────┐
  │                                         │  ← 未入力・エラー時は赤枠（border-red-500）
  └─────────────────────────────────────────┘
  ⚠ レシピ名を入力してください                   ← text-red-500 text-sm
```

- エラーがある項目の入力枠は赤枠（`border-red-500`）で強調表示
- 入力枠の下にエラーメッセージを赤文字（`text-red-500`）で表示
- 送信ボタンはエラーがあっても押せる（送信時にエラーを表示）

## 3. 画像アップロードのバリデーション

対象: `POST /api/upload`

### 3.1 検証項目

| No. | 検証項目 | 実施場所 | 仕様 |
|-----|---------|---------|------|
| 1 | ファイル未選択 | フロントエンド | 画像は任意のため何もしない |
| 2 | ファイル形式 | フロントエンド + サーバーサイド | JPEG・PNG・WebP・GIF のみ許可 |
| 3 | ファイルサイズ | フロントエンド + サーバーサイド | 4MB（4,194,304 バイト）以下 |

### 3.2 対応 MIME タイプ

| 拡張子 | MIME タイプ |
|--------|-----------|
| .jpg / .jpeg | `image/jpeg` |
| .png | `image/png` |
| .webp | `image/webp` |
| .gif | `image/gif` |

### 3.3 エラーメッセージ

| 条件 | エラーメッセージ |
|------|----------------|
| ファイル形式が対応外 | 「対応していないファイル形式です（JPEG / PNG / WebP / GIF）」 |
| ファイルサイズが超過 | 「ファイルサイズは4MB以下にしてください」 |

エラーはフォームの画像アップロードエリア内に表示する。

## 4. サーバーサイドバリデーション

API Routes で行うバリデーションの詳細。

### POST /api/recipes（レシピ作成）

| 項目 | 検証内容 | エラー時のレスポンス |
|------|---------|-------------------|
| title | 存在確認・255文字以内 | `400 { error: 'タイトルは必須です' }` |
| ingredients | 存在確認 | `400 { error: '材料は必須です' }` |
| instructions | 存在確認 | `400 { error: '作り方は必須です' }` |
| categoryId | 存在する場合: 数値か確認 | `400 { error: '無効なカテゴリIDです' }` |
| cookTime | 存在する場合: 正の整数か確認 | `400 { error: '調理時間は正の整数で入力してください' }` |
| servings | 存在する場合: 正の整数か確認 | `400 { error: '人数は正の整数で入力してください' }` |

### POST /api/upload（画像アップロード）

| 項目 | 検証内容 | エラー時のレスポンス |
|------|---------|-------------------|
| ファイル | multipart/form-data に含まれているか | `400 { error: 'ファイルが選択されていません' }` |
| MIME タイプ | 対応形式（JPEG/PNG/WebP/GIF）か | `400 { error: '対応していないファイル形式です' }` |
| ファイルサイズ | 4MB 以下か | `400 { error: 'ファイルサイズが上限を超えています' }` |

### DELETE /api/recipes/[id]・PUT /api/recipes/[id]

| 項目 | 検証内容 | エラー時のレスポンス |
|------|---------|-------------------|
| id | 数値か確認 | `400 { error: '無効なIDです' }` |
| レシピ存在確認 | DB にレコードがあるか | `404 { error: 'レシピが見つかりません' }` |
