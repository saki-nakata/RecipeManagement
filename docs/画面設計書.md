## S-02 レシピ登録ページ（`/recipes/new`）

**機能:** F-03・F-06・F-07

```
┌─────────────────────────────────────────────────┐
│ 🍳 レシピ管理アプリ         [＋ レシピを追加]     │ ← Navbar
├─────────────────────────────────────────────────┤
│                                                 │
│  新しいレシピを登録                               │  ← 戻るボタンなし（Navbar から一覧へ）
│  ─────────────────────────────────────────      │
│                                                 │
│  レシピ名 *                                      │
│  ┌─────────────────────────────────────────┐   │
│  │ 例）鶏の唐揚げ                            │   │  ← 白背景
│  └─────────────────────────────────────────┘   │
│                                                 │
│  カテゴリ（未選択時は「その他」を自動設定）          │
│  ┌─────────────────────────────────────────┐   │
│  │ 選択してください（デフォルト: その他）  ▼  │   │  ← 白背景
│  └─────────────────────────────────────────┘   │
│                                                 │
│  画像                                            │
│  ┌──────────────────────────────────────────┐  │
│  │     📷 クリックして画像を選択、またはD&D  │  │
│  │     JPEG / PNG / WebP / GIF、4MB以下      │  │
│  └──────────────────────────────────────────┘  │
│                                                 │
│  説明文                                          │
│  ┌─────────────────────────────────────────┐   │
│  │ このレシピの説明を入力してください...      │   │  ← 白背景
│  └─────────────────────────────────────────┘   │
│                                                 │
│  ┌─────────────────┐  ┌──────────────────────┐ │
│  │ 調理時間（分）   │  │ 何人前               │ │
│  │ ┌───────┐       │  │ ┌───────┐            │ │
│  │ │  30   │       │  │ │   2   │            │ │  ← 白背景
│  │ └───────┘       │  │ └───────┘            │ │
│  └─────────────────┘  └──────────────────────┘ │
│                                                 │
│  材料 *                                          │
│  ┌──────────────────────────┬───────────────┐  │
│  │ 材料名（例：鶏もも肉）    │ 分量（例：500g）│ [✕] │  ← 白背景
│  ├──────────────────────────┼───────────────┤  │
│  │ 材料名（例：塩）          │ 分量（例：適量）│ [✕] │
│  └──────────────────────────┴───────────────┘  │
│  ＋ 材料を追加                                   │
│                                                 │
│  作り方 *                                        │
│  ┌────┬──────────────────────────────────┬───┐ │
│  │ 1  │ ステップ1を入力...               │ ✕ │ │  ← 白背景
│  ├────┼──────────────────────────────────┼───┤ │
│  │ 2  │ ステップ2を入力...               │ ✕ │ │
│  └────┴──────────────────────────────────┴───┘ │
│  ＋ ステップを追加                               │
│                                                 │
│  💡 ポイント・コツ                               │
│  ┌─────────────────────────────────────────┐   │
│  │ おいしく作るポイントやコツを書いてみましょう │   │  ← 白背景
│  └─────────────────────────────────────────┘   │
│                                                 │
│  * は必須項目                                    │
│                                                 │
│           [キャンセル]          [登録する]        │  ← → なし・font-semibold
│                                                 │

```

**フォーム入力項目の順序:** レシピ名 → カテゴリ → 画像 → 説明文 → 調理時間/何人前 → 材料 → 作り方 → ポイント・コツ

## S-03 レシピ詳細ページ（`/recipes/[id]`）

**機能:** F-02・F-05・F-08

```
┌─────────────────────────────────────────────────┐
│ 🍳 レシピ管理アプリ         [＋ レシピを追加]     │ ← Navbar（一覧へはNavbarから）
├─────────────────────────────────────────────────┤
│                                                 │
│ ┌─────────────────────────────────────────────┐ │
│ │                                             │ │
│ │              レシピ画像                      │ │  ← max-height: 380px、object-contain（背景 #F9FAFB）
│ │                                             │ │
│ └─────────────────────────────────────────────┘ │
│                                                 │
│  鶏の唐揚げ                                      │ ← モバイルはタイトルのみ1行目
│  [♡ お気に入り] [✎ 編集] [🗑 削除]               │ ← モバイルはボタン群が2行目（sm以上で横並び）
│  ─────────────────────────────────────────────  │
│  🥩 肉料理  ⏱ 30分  👥 2人前                    │
│                                                 │
│  📝 説明                                        │  ← 2px オレンジライン区切り
│  サクサクジューシーな唐揚げのレシピです。           │
│                                                 │
│  🥕 材料                                        │  ← 2px オレンジライン区切り
│  ┌──────────────────────────────────────────┐  │
│  │ ● 鶏もも肉　500g                         │  │  ← 薄オレンジ背景カード
│  ├──────────────────────────────────────────┤  │
│  │ ● 醤油　大さじ3                          │  │
│  └──────────────────────────────────────────┘  │
│                                                 │
│  👨‍🍳 作り方                                     │  ← 2px オレンジライン区切り
│  ┌──┐ 鶏肉を一口大に切る                         │  ← ① 薄オレンジ背景の番号
│  │ 1│                                           │
│  └──┘                                           │
│  ┌──┐ 醤油・酒・にんにくで30分漬け込む            │
│  │ 2│                                           │
│  └──┘                                           │
│                                                 │
│  💡 ポイント・コツ                               │  ← 2px オレンジライン区切り
│  ┌─────────────────────────────────────────┐   │
│  │ 二度揚げするとカリッと仕上がります。        │   │  ← アンバー背景ボックス
│  └─────────────────────────────────────────┘   │
│                                                 │
└─────────────────────────────────────────────────┘
```

**アクションボタン仕様:**

| ボタン | デフォルト | ホバー |
|-------|-----------|-------|
| お気に入り（未登録） | 薄オレンジ枠・グレー文字 | 赤背景・赤文字 |
| お気に入り（登録済） | 赤背景・赤文字 | — |
| 編集 | 薄オレンジ枠・グレー文字 | 薄オレンジ背景・オレンジ文字 |
| 削除 | 薄オレンジ枠・グレー文字 | 赤背景・赤文字 |

**セクション表示順:** 説明文 → 材料 → 作り方 → ポイント・コツ（存在する場合のみ表示）

**削除確認ダイアログ:**
```
┌──────────────────────────────────┐
│                                  │
│  レシピを削除                     │
│                                  │
│  「鶏の唐揚げ」を削除します。        │
│  この操作は取り消せません。          │
│                                  │
│    [キャンセル]    [削除する]       │
│                                  │
└──────────────────────────────────┘
```

## S-04 レシピ編集ページ（`/recipes/[id]/edit`）

**機能:** F-04・F-06・F-07

S-02（登録ページ）と同じレイアウト。以下の点のみ異なる。

| 差分 | 登録ページ（S-02） | 編集ページ（S-04） |
|------|-----------------|-----------------|
| 戻るボタン | なし | 「◀ 詳細に戻る」（薄オレンジ枠・pill 型） |
| タイトル | 「新しいレシピを登録」 | 「レシピを編集」 |
| 初期値 | 空欄 | 既存データが入力済み |
| 画像表示 | アップロードエリアのみ | 現在の画像プレビューあり（h-48 object-contain、背景 #F9FAFB、削除ボタン付き） |
| 送信ボタン | 「登録する」 | 「更新する」 |
| 成功後の遷移 | 一覧ページ | 詳細ページ |

## 共通 UI コンポーネント

### Navbar

```
┌─────────────────────────────────────────────────┐
│ 🍳 レシピ管理アプリ         [＋ レシピを追加]     │
└─────────────────────────────────────────────────┘
```

- 背景色: `#FFEDD5`（薄オレンジ）、下ボーダー: `#FED7AA`
- 🍳 アイコン: ゆっくり揺れるアニメーション付き
- 「レシピ管理アプリ」: オレンジグラデーション・font-extrabold・クリックで `/` へ遷移
- 「レシピを追加」: 薄オレンジ背景・オレンジ文字・pill 型、ホバーで少し濃く

### RecipeCard（カード）

```
┌──────────────────┐
│                  │
│   レシピ画像      │  ← h-48 object-contain（背景 #F9FAFB、未設定時はカテゴリ色プレースホルダー）
│               ♡  │  ← お気に入りボタン（右上オーバーレイ）
├──────────────────┤
│ レシピ名          │  ← font-bold text-base、2行まで表示
│ 🍚 ご飯もの      │  ← カテゴリバッジ（淡色背景）
│ ⏱30分  👥2人前  │  ← 設定がある場合のみ表示
└──────────────────┘
```

カード全体がクリック可能（`/recipes/[id]` へ遷移）。ホバーで上に浮き上がるアニメーション。
