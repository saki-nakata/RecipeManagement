## S-01 レシピ一覧ページ（`/`）

**機能:** F-01・F-09・F-10・F-11・F-12

```
┌─────────────────────────────────────────────────┐
│  レシピ管理アプリ                                 │ ← Navbar（アイコンなし・テキストのみ）
├─────────────────────────────────────────────────┤
│                                                 │
│  レシピ一覧                  [＋ レシピを追加]   │ ← ページヘッダー（追加ボタンは枠線のみ・右寄せ）
│  おいしいレシピをみつけよう                       │
│                                                 │
│ 🔍 キーワードで検索...  [カテゴリ▼] [❤お気に入り] [並び替え▼] │ ← フィルタバー
├──────────────┬──────────────┬───────────────────┤
│ [黄背景:画像] │ [橙背景:画像] │ [赤背景:画像]      │
│            ♡ │            ♡ │                 ♡ │ ← お気に入りボタン
│ レシピ名      │ レシピ名      │ レシピ名           │
│ 🍚 ご飯      │ 🍜 麺類      │ 🥩 肉料理          │ ← カテゴリバッジ（カテゴリ色）
│ ⏱30分 👥2人前│ ⏱20分       │ ⏱60分 👥4人前     │
├──────────────┼──────────────┼───────────────────┤
│ ...          │ ...          │ ...               │
└──────────────┴──────────────┴───────────────────┘
```

**カテゴリ別カラー:**

| カテゴリ | 背景色 | 文字色 |
|---------|--------|--------|
| ご飯 🍚 | #FFF9C4 | #796600 |
| 麺類 🍜 | #FFE0B2 | #8B4513 |
| 肉料理 🥩 | #FFCDD2 | #B71C1C |
| 魚料理 🐟 | #BBDEFB | #1A237E |
| 野菜料理 🥗 | #DCEDC8 | #1B5E20 |
| スープ 🍲 | #F8BBD0 | #880E4F |
| デザート 🍰 | #E1BEE7 | #4A148C |
| パン 🍞 | #FFF3E0 | #BF360C |
| 飲み物 🍹 | #B2EBF2 | #006064 |
| その他 🍽 | #EEEEEE | #424242 |

**並び替えオプション:** 新着順 / 古い順 / 名前順 / 調理時間順

**レスポンシブ対応:**

| ブレークポイント | カラム数 | 幅の目安 |
|---------------|---------|---------|
| スマートフォン | 1列 | 〜640px |
| タブレット | 2列 | 640px〜1024px |
| PC | 3列 | 1024px〜 |

## S-04 レシピ編集ページ（`/recipes/[id]/edit`）

**機能:** F-04・F-06・F-07

S-02（登録ページ）と同じレイアウト。以下の点のみ異なる。

| 差分 | 登録ページ（S-02） | 編集ページ（S-04） |
|------|-----------------|-----------------|
| 戻るボタン | 「◀ 一覧に戻る」 | 「◀ 詳細に戻る」 |
| タイトル | 「新しいレシピを登録」 | 「レシピを編集」 |
| 初期値 | 空欄 | 既存データが入力済み |
| 画像表示 | アップロードエリアのみ | 現在の画像プレビューあり（削除ボタン付き） |
| 送信ボタン | 「登録する →」 | 「更新する →」 |
| 成功後の遷移 | 一覧ページ | 詳細ページ |

## 共通 UI コンポーネント

### Navbar

```
┌─────────────────────────────────────────────────┐
│  レシピ管理アプリ                                 │
└─────────────────────────────────────────────────┘
```

- アプリ名テキストのみ（絵文字アイコンなし）
- クリックでトップページ（`/`）へ遷移
- 「レシピを追加」ボタンは Navbar に置かず、S-01 ページヘッダーにのみ表示

### RecipeCard（カード）

```
┌──────────────────┐
│                  │
│   レシピ画像      │  ← h-48 object-cover（未設定時はプレースホルダー）
│               ♡  │  ← お気に入りボタン（右上オーバーレイ）
├──────────────────┤
│ レシピ名          │  ← font-bold text-lg、2行まで表示
│ 🍚 ご飯もの      │  ← カテゴリバッジ（emoji + 名前）
│ ⏱30分  👥2人前  │  ← 設定がある場合のみ表示
└──────────────────┘
```

カード全体がクリック可能（`/recipes/[id]` へ遷移）。
