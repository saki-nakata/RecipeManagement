│ 🍳 レシピ管理アプリ                               │ ← Navbar
├─────────────────────────────────────────────────┤

│ │                                             │ │

│                                                 │
│  ── 説明文 ─────────────────────────────────    │
│  サクサクジューシーな唐揚げのレシピです。           │

│                                                 │
│  ── 材料 ───────────────────────────────────    │
│  ・鶏もも肉 300g                                 │
│  ・醤油 大さじ2                                  │
│  ・みりん 大さじ1                                 │
│  ・にんにく 1かけ                                 │
│  ・片栗粉 適量                                   │
│  ・揚げ油 適量                                   │

## S-04 レシピ編集ページ（`/recipes/[id]/edit`）

**機能:** F-04・F-06・F-07

S-02（登録ページ）と同じレイアウト。以下の点のみ異なる。

| 差分 | 登録ページ（S-02） | 編集ページ（S-04） |
|------|-----------------|-----------------|
| タイトル | 「新しいレシピを登録」 | 「レシピを編集」 |
| 初期値 | 空欄 | 既存データが入力済み |
| 画像表示 | アップロードエリアのみ | 現在の画像プレビューあり |
| 送信ボタン | 「登録する →」 | 「更新する →」 |
| 成功後の遷移 | 一覧ページ | 詳細ページ |

## 共通 UI コンポーネント

### Navbar

```
┌─────────────────────────────────────────────────┐
│ 🍳 レシピ管理アプリ              [+ レシピを追加] │
└─────────────────────────────────────────────────┘
```

- ロゴ・アプリ名（左）: トップページへのリンク
- 「+ レシピを追加」ボタン（右）: `/recipes/new` へのリンク

### RecipeCard（カード）

```
┌──────────────────┐
│                  │
│   レシピ画像      │  ← h-48 object-cover（未設定時はプレースホルダー）
│               ♡  │  ← お気に入りボタン（右上オーバーレイ）
├──────────────────┤
│ レシピ名          │  ← font-bold text-lg、2行まで表示
│ 🍚 ご飯もの      │  ← カテゴリバッジ（emoji + 名前）
│ ⏱30分  👥2人前  │  ← 設定がある場合のみ表示
└──────────────────┘
```

カード全体がクリック可能（`/recipes/[id]` へ遷移）。
